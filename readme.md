# Proje Yönetim Discord Botu

Python ve Discord.py kullanılarak geliştirilmiş bu bot, projelerinizi Discord üzerinden kolayca yönetmenizi sağlar.

## Özellikler

- Yeni proje ekleme
- Projeleri listeleme
- Proje bilgilerini güncelleme
- Projeye beceri ekleme
- Proje silme
- Proje görsellerini kaydetme
- SQLite veritabanı kullanımı
- Discord butonları ve modal pencereleri

## Kullanılan Teknolojiler

- Python
- Discord.py
- SQLite
- Discord API

Bu proje, Discord üzerinde proje takibini kolaylaştırmak amacıyla geliştirilmiştir.
